## 开始使用

### 1.1 小程序入口

1. 打开微信
2. 搜索"清如"或"日行一善"
3. 点击进入小程序

### 1.2 用户注册

1. 首次进入需要微信授权登录
2. 选择用户角色：
   - **祈福者**: 委托护生、积累功德
   - **执行者**: 承接任务、执行护生
   - **机构**: 管理志愿者、承接订单

### 1.3 实名认证

**祈福者**:
- 无需实名认证即可使用基础功能
- 委托护生需要实名认证

**执行者**:
- 必须完成实名认证
- 上传身份证照片
- 等待审核（1-3 个工作日）

**机构**:
- 必须完成机构认证
- 上传营业执照
- 等待审核（3-5 个工作日）

## 祈福者指南

### 2.1 首页功能

**每日佛历**:
- 查看公历、农历、干支纪年
- 查看每日宜忌

**禅理短句**:
- 随机获取禅理短句
- 收藏喜欢的短句
- 分享给朋友

**梵音播放**:
- 选择佛曲播放
- 支持后台播放
- 查看收听记录

### 2.2 功德林

**自主护生**:
1. 点击"功德林"
2. 选择"自主护生"
3. 填写护生信息：
   - 物种名称
   - 数量
   - 地点
   - 时间
   - 上传照片
4. 提交后获得功德证书

**委托护生**:
1. 点击"委托护生"
2. 选择物种和数量
3. 选择承接机构
4. 支付费用
5. 等待执行
6. 查看执行结果

### 2.3 订单管理

**查看订单**:
1. 点击"我的"
2. 选择"我的订单"
3. 查看订单状态：
   - 待支付
   - 待执行
   - 执行中
   - 已完成

**订单详情**:
- 查看订单信息
- 查看执行进度
- 查看执行结果（照片、视频）
- 下载证书

### 2.4 证书管理

**查看证书**:
1. 点击"我的"
2. 选择"我的证书"
3. 按分类筛选：
   - 自主护生证书
   - 委托护生证书
   - 其他证书

**证书操作**:
- 查看证书详情
- 分享到朋友圈
- 下载证书图片
- 批量管理

### 2.5 个人中心

**个人信息**:
- 查看个人资料
- 编辑个人信息
- 实名认证

**修行数据**:
- 累计护生次数
- 累计护生数量
- 累计功德值
- 收听记录

**设置**:
- 推送通知设置
- 缓存管理
- 隐私设置
- 关于我们

## 执行者指南

### 3.1 资质审核

**申请成为执行者**:
1. 点击"我的"
2. 选择"申请成为执行者"
3. 填写个人信息
4. 上传身份证照片
5. 等待审核

**审核状态**:
- 待审核
- 审核通过
- 审核失败（可查看原因重新提交）

### 3.2 抢单大厅

**查看订单**:
1. 点击"抢单大厅"
2. 查看可承接订单
3. 筛选条件：
   - 物种类型
   - 地点范围
   - 报酬范围

**承接订单**:
1. 选择订单
2. 查看订单详情
3. 点击"承接"
4. 等待确认

### 3.3 任务执行

**任务列表**:
- 待执行
- 执行中
- 已完成

**执行任务**:
1. 点击任务
2. 查看详情
3. 前往执行地点
4. 拍摄执行过程（照片/视频）
5. 提交执行结果

**提交执行结果**:
1. 填写执行信息
2. 上传照片/视频
3. 提交等待审核
4. 审核通过后获得报酬

### 3.4 收入管理

**收入明细**:
- 查看每笔收入
- 收入统计（日/周/月）

**提现**:
1. 点击"提现"
2. 选择提现金额
3. 选择提现账户
4. 提交申请
5. 1-3 个工作日到账

## 常见问题

### 5.1 账号问题

**Q: 如何修改手机号？**
A: 目前不支持修改手机号，如需修改请联系客服。

**Q: 如何注销账号？**
A: 在"设置"中选择"注销账号"，注销后数据将无法恢复。

### 5.2 护生问题

**Q: 自主护生需要什么条件？**
A: 完成实名认证后即可进行自主护生。

**Q: 委托护生的费用如何计算？**
A: 根据物种、数量、地点等因素计算，下单前会显示详细费用。

**Q: 如何查看护生执行结果？**
A: 在"我的订单"中查看订单详情，可看到执行照片、视频等。

### 5.3 证书问题

**Q: 证书如何下载？**
A: 在证书详情页点击"下载证书"即可保存到手机。

**Q: 证书可以分享给朋友吗？**
A: 可以，点击"分享"即可分享到朋友圈或好友。

### 5.4 支付问题

**Q: 支持哪些支付方式？**
A: 目前仅支持微信支付。

**Q: 支付失败怎么办？**
A: 请检查网络情况和微信余额，如仍失败请联系客服。

### 5.5 提现问题

**Q: 提现多久到账？**
A: 1-3 个工作日到账。

**Q: 提现有限额吗？**
A: 单笔最低 10 元，最高 10000 元。
