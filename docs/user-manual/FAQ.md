## 账号问题

### Q1: 如何注册账号？

**A**: 清如小程序使用微信授权登录，无需单独注册。
1. 打开清如小程序
2. 点击"微信登录"
3. 授权即可自动注册

### Q2: 如何修改个人信息？

**A**: 
1. 点击"我的"
2. 点击头像或"编辑资料"
3. 修改信息后保存

**注意**: 昵称和头像会从微信同步，不可手动修改。

### Q3: 如何修改手机号？

**A**: 目前不支持修改手机号，因为小程序使用微信绑定。如需更换微信，请重新授权登录。

### Q4: 如何注销账号？

**A**: 
1. 点击"我的"
2. 选择"设置"
3. 点击"注销账号"
4. 阅读注销协议并确认

**注意**: 注销后所有数据将无法恢复，请谨慎操作。

### Q5: 实名认证需要多长时间？

**A**: 
- 个人认证：1-3 个工作日
- 机构认证：3-5 个工作日

### Q6: 实名认证失败怎么办？

**A**: 
1. 查看失败原因
2. 重新准备材料
3. 再次提交认证

常见失败原因：
- 身份证照片不清晰
- 身份证信息过期
- 身份证照片与本人不符

## 护生问题

### Q7: 什么是自主护生？

**A**: 自主护生是指用户自行进行护生活动，并在小程序中登记记录。
- 无需支付费用
- 需要上传护生照片
- 审核通过后获得证书

### Q8: 什么是委托护生？

**A**: 委托护生是指用户委托专业机构或执行者进行护生活动。
- 需要支付费用
- 由专业人士执行
- 提供完整执行记录
- 获得官方证书

### Q9: 护生物种有哪些限制？

**A**: 
**禁止放生物种**:
- 外来入侵物种（如巴西龟、鳄龟等）
- 可能破坏生态平衡的物种
- 法律法规禁止的物种

**推荐放生物种**:
- 本地常见物种
- 适合当地环境的物种
- 无生态风险的物种

### Q10: 如何选择合适的放生地点？

**A**: 
1. 选择适合物种生存的环境
2. 避开污染水域
3. 避开人类活动频繁区域
4. 遵守当地法律法规
5. 咨询专业人士建议

### Q11: 护生后多久能看到记录？

**A**: 
- 自主护生：提交后立即显示，审核后获得证书
- 委托护生：执行完成后 1-3 天内显示

### Q12: 如何查看我的护生记录？

**A**: 
1. 点击"功德林"
2. 选择"我的护生"
3. 查看所有护生记录

## 支付问题

### Q13: 支持哪些支付方式？

**A**: 目前仅支持微信支付。

### Q14: 支付失败怎么办？

**A**: 
1. 检查网络连接
2. 检查微信余额或绑定银行卡
3. 检查支付限额
4. 重新尝试支付
5. 如仍失败，请联系客服

### Q15: 支付成功后订单状态未更新？

**A**: 
1. 等待 1-2 分钟（系统同步延迟）
2. 下拉刷新订单列表
3. 如仍未更新，请联系客服并提供支付凭证

### Q16: 如何申请退款？

**A**: 
**可退款情况**:
- 订单未执行
- 执行失败
- 其他特殊情况

**退款流程**:
1. 联系在线客服
2. 说明退款原因
3. 提供订单号
4. 等待审核（1-3 个工作日）
5. 审核通过后原路退回

### Q17: 发票如何开具？

**A**: 
1. 订单完成后
2. 点击"我的"
3. 选择"发票管理"
4. 填写发票信息
5. 提交申请
6. 电子发票将发送到邮箱

## 证书问题

### Q18: 证书如何获得？

**A**: 
**自主护生**:
1. 提交护生记录
2. 上传照片
3. 审核通过
4. 自动生成证书

**委托护生**:
1. 完成订单
2. 执行完成
3. 自动生成证书

### Q19: 证书可以下载吗？

**A**: 可以。
1. 打开证书详情
2. 点击"下载证书"
3. 保存到手机相册

### Q20: 证书可以分享吗？

**A**: 可以。
1. 打开证书详情
2. 点击"分享"
3. 选择分享到朋友圈或好友

### Q21: 证书丢失了怎么办？

**A**: 
1. 点击"我的"
2. 选择"我的证书"
3. 找到对应证书
4. 重新下载

所有证书永久保存在云端，可随时查看和下载。

### Q22: 证书有有效期吗？

**A**: 证书永久有效，无过期时间。

## 提现问题

### Q23: 执行者如何提现？

**A**: 
1. 点击"我的"
2. 选择"收入管理"
3. 点击"提现"
4. 选择提现金额
5. 选择提现账户
6. 提交申请

### Q24: 提现多久到账？

**A**: 1-3 个工作日到账。

### Q25: 提现有限额吗？

**A**: 
- 最低提现：10 元
- 单笔最高：10000 元
- 每日最高：50000 元
- 每月最高：200000 元

### Q26: 提现失败怎么办？

**A**: 
1. 检查提现账户信息是否正确
2. 检查是否超过限额
3. 检查账户状态是否正常
4. 联系客服处理

### Q27: 机构如何提现？

**A**: 
机构提现需使用对公账户：
1. 点击"我的"
2. 选择"结算管理"
3. 点击"提现"
4. 填写对公账户信息
5. 提交申请

## 技术问题

### Q28: 小程序无法打开怎么办？

**A**: 
1. 检查网络连接
2. 退出微信重新进入
3. 删除小程序后重新搜索进入
4. 检查微信版本是否过低
5. 联系技术支持

### Q29: 页面加载缓慢怎么办？

**A**: 
1. 检查网络连接
2. 清理小程序缓存
3. 关闭后台其他应用
4. 重启微信

### Q30: 图片无法上传怎么办？

**A**: 
1. 检查图片大小（不超过 10MB）
2. 检查图片格式（支持 JPG、PNG）
3. 检查网络连接
4. 重新尝试上传

### Q31: 音频无法播放怎么办？

**A**: 
1. 检查手机音量
2. 检查是否静音模式
3. 退出后台重新进入
4. 检查耳机连接

### Q32: 收不到推送通知怎么办？

**A**: 
1. 检查手机通知设置
2. 检查小程序通知权限
3. 检查小程序内推送设置
4. 重新授权通知权限

## 其他问题

### Q33: 如何联系客服？

**A**: 
- **客服微信**: QingRuKeFu
- **服务时间**: 9:00-21:00
- **反馈入口**: 小程序内"我的" - "帮助与反馈"

### Q34: 客服响应时间？

**A**: 
- 一般问题：24 小时内回复
- 紧急问题：2 小时内回复
- 投诉建议：3 个工作日内回复

### Q35: 如何反馈意见或建议？

**A**: 
1. 点击"我的"
2. 选择"帮助与反馈"
3. 选择"意见反馈"
4. 填写反馈内容
5. 提交

### Q36: 小程序有广告吗？

**A**: 清如小程序永久无广告，所有收入用于平台运营和护生活动。

### Q37: 我的数据安全吗？

**A**: 
- 所有数据加密存储
- 严格遵守隐私政策
- 不向第三方泄露个人信息
- 符合微信数据安全规范

### Q38: 如何查看隐私政策？

**A**: 
1. 点击"我的"
2. 选择"设置"
3. 点击"隐私政策"

### Q39: 小程序支持哪些地区？

**A**: 目前仅支持中国大陆地区。

### Q40: 小程序支持哪些语言？

**A**: 目前仅支持简体中文。
