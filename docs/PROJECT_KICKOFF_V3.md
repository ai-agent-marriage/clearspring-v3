## 1. 项目概况

### 1.1 项目背景

「清如」是一款主打**禅意静心、科学护生**的微信小程序，以"**积善成德，虚极静笃**"为核心理念。

**V3.0 版本**是在 V2.0 基础上的全面重构，基于 19 个精选开源项目，采用多 Agent 协同开发模式，确保 4 周内高质量完成开发。

### 1.2 基本信息

| 项目要素 | 详细信息 |
|----------|----------|
| **项目名称** | 清如 ClearSpring V3.0 |
| **项目类型** | 微信小程序 + WEB 管理后台 |
| **技术栈** | 微信原生小程序 + Java(RuoYi-Vue) + MySQL |
| **开发周期** | 4 周（2026-04-07 ~ 2026-05-04） |
| **GitHub 仓库** | https://github.com/ai-agent-marriage/clearspring-v3 |
| **AppID** | wxa914ecc15836bda6 |
| **开发环境** | OpenClaw + 多 Agent 协同 |

### 1.3 核心服务

- 🎵 **梵音板块**: 9 首固定禅意音频播放、收听统计、里程碑证书
- 📖 **禅理板块**: 每日一禅、物种查询、佛历吉日、护生功德林
- 🙏 **护生服务**: 免费自主护生登记 + 付费委托护生服务（双链路）
- 👤 **个人中心**: 修行数据看板、护生台账、证书库、打卡日历
- 👷 **践行者端**: 志愿者任务管理 + 机构订单管理
- 🖥️ **WEB 后台**: 超级管理员全功能管理（用户/订单/内容/财务/系统）

## 2. 产品定位与目标

### 2.1 产品定位

**合规定位**: 禅意静心 + 科学护生（弱化宗教属性，强化生态保护）

**核心理念**: 积善成德，虚极静笃

**目标用户**:
- **祈福者**: 寻求内心宁静、参与公益护生的 C 端用户
- **志愿者**: 参与护生执行的公益志愿者
- **机构**: 具备护生资质的企业/公益组织

### 2.2 产品目标

#### 短期目标（上线 1-3 个月）
- ✅ 完成核心功能落地，顺利通过微信小程序审核
- ✅ 积累 1000+ 种子用户
- ✅ 核心功能使用率≥60%
- ✅ 跑通护生委托服务全流程闭环

#### 中期目标（上线 3-6 个月）
- ✅ 完善内容体系，打造科学护生垂直场景差异化优势
- ✅ 用户月留存率≥40%
- ✅ 付费委托订单月转化率≥15%

#### 长期目标
- ✅ 成为国内垂直于正念静心、科学护生领域的标杆小程序
- ✅ 构建"内容 - 服务 - 公益 - 记录"的完整用户闭环
- ✅ 形成合规可持续的商业模式

### 2.3 核心风险与应对

| 风险类型 | 风险描述 | 应对措施 |
|----------|----------|----------|
| **审核风险** | 微信小程序对宗教相关、放生类内容有严格审核规则 | 1. 全流程替换为"科学护生"<br>2. 付费入口深度隐藏<br>3. 全页面固定合规提示<br>4. 入侵物种红标警示<br>5. 弱化宗教传教内容 |
| **内容风险** | 禅理内容、用户上传内容存在违规风险 | 1. 优先选用国学正念内容<br>2. 接入微信内容安全 API<br>3. 建立人工二次审核<br>4. 搭建敏感词库 |
| **隐私风险** | 微信授权、个人信息收集合规风险 | 1. 遵循《个人信息保护法》<br>2. 不强制注册授权<br>3. 公示用户协议与隐私政策<br>4. 敏感信息加密存储 |
| **执行风险** | 护生执行端出现违规行为 | 1. 机构必须具备合规资质<br>2. 全流程强制合规承诺<br>3. 建立黑白名单制度<br>4. 全流程记录永久归档 |

## 3. 核心功能架构

### 3.1 用户端（微信小程序）

**3 大板块**: 梵音、禅理、我的

**3 类角色**: 
- **祈福者**（默认）: 免注册可使用基础功能
- **志愿者**（个人践行者）: 微信实名认证 + 合规承诺
- **机构**（合规执行机构）: 资质审核通过后入驻

**7 个核心页面**: 
- 首页（佛历吉日）
- 梵音音频列表/播放页
- 禅理双首页
- 物种查询/详情页
- 护生功德林
- 个人中心
- 证书库

**2 条业务链路**: 
- **免费自主护生登记**: 用户自行完成护生行动后免费登记
- **付费委托护生服务**: 委托合规执行机构完成护生执行（核心盈利模块）

### 3.2 管理端（WEB 后台）

**5 类角色**: 
- 超级管理员
- 机构管理员
- 内容运营专员
- 合规审核专员
- 财务专员

**6 大模块**: 
- **控制台**: 数据大盘、待办事项、运营数据趋势图
- **用户管理**: 祈福者/志愿者/机构全生命周期管理
- **订单管理**: 委托订单全量管理、自主护生记录审核
- **内容管理**: 禅理/物种/证书/合规水域配置
- **财务管理**: 订单对账、平台服务费、结算管理、发票管理
- **系统设置**: 小程序配置、支付配置、消息通知、日志管理

### 3.3 订单状态流转

```
待承接 (1) → 待执行 (2) → 执行中 (3) → 待确认 (4) → 已完成 (5) → 已结算 (6)
```

**异常流程**:
- 48 小时无机构承接 → 自动取消，全额退款
- 用户申请复核 → 机构 48 小时内回复
- 订单违规 → 平台审核驳回，全额退款

**加载规范**:

- 列表页：骨架屏

## 13. 合规与风险控制

### 13.1 合规措施

**关键词替换**:
- ✅ 放生 → 科学护生（全文字替换）
- ✅ 佛法 → 禅理/正念
- ✅ 功德 → 修行数据

**入口隐藏**:
- ✅ 付费入口二级隐藏（仅注册用户可见）
- ✅ 默认展示免费公益功能
- ✅ 无首屏强引导

**强制合规**:
- ✅ 合规承诺书（用户必须同意）
- ✅ 入侵物种红标禁止（正面清单管理）
- ✅ 未成年人支付限制
- ✅ 内容双审核（机器 + 人工）

**敏感元素规避**:
- ✅ 证书/海报无宗教敏感元素
- ✅ 使用"禅理"而非"佛法"
- ✅ 使用"修行"而非"念佛"

### 13.2 内容安全

**审核流程**:
```
用户上传 → 微信内容安全 API 机审 → 人工二次审核 → 审核通过/驳回
```

**敏感词库**:
- 宗教传教类词汇
- 政治敏感词汇
- 色情暴力词汇
- 广告营销词汇

**审核日志**:
- 全量记录审核操作
- 审核人、审核时间、审核结果
- 永久归档留存

### 13.3 数据安全

**敏感信息加密**:
- 用户手机号脱敏存储（138****1234）
- 身份证号脱敏存储
- 支付信息加密传输

**权限控制**:
- RBAC 权限模型
- 后台操作全程留痕
- 禁止越权操作

**数据备份**:
- 数据库定期备份（每日/每周/每月）
- 备份文件多地存储
- 数据恢复演练
