# 微信小程序灰度发布配置

## 配置说明

### 微信公众平台设置

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 进入「版本管理」
3. 点击「灰度发布」
4. 配置灰度参数

### 灰度参数配置

```yaml
# 灰度发布配置
canary_release:
  # 灰度比例
  percentage: 10%  # 10% 的用户
  
  # 灰度时长
  duration: 7d     # 7 天
  
  # 灰度目标
  goal: 验证稳定性
  
  # 灰度策略
  strategy:
    - stage: 内部测试
      days: 1-2
      percentage: 5%
      target: 内部员工 + 核心用户
    
    - stage: 扩大测试
      days: 3-5
      percentage: 10%
      target: 活跃用户
    
    - stage: 大规模测试
      days: 6-7
      percentage: 30%
      target: 随机用户
    
    - stage: 全量发布
      days: 8+
      percentage: 100%
      target: 所有用户
```

## 灰度用户选择策略

### 1. 基于用户 ID 哈希
```javascript
// 根据用户 OpenID 哈希值决定是否灰度
function isInCanary(openId, percentage) {
  const hash = md5(openId)
  const hashNum = parseInt(hash.substring(0, 8), 16)
  return (hashNum % 100) < percentage
}
```

### 2. 基于用户标签
- 内部员工（必选）
- 核心用户（优先）
- 活跃用户（次优先）
- 随机用户（最后）

### 3. 基于地域
- 先选择特定城市
- 逐步扩大范围

## 监控指标

### 技术指标
- 崩溃率 < 0.1%
- 接口错误率 < 1%
- 页面加载时间 < 2s
- API 响应时间 < 500ms

### 业务指标
- 日活跃用户数 (DAU)
- 功能使用率
- 用户留存率
- 用户反馈数量

### 用户体验指标
- NPS (净推荐值)
- 用户满意度
- 投诉率

## 回滚流程

### 触发条件
- 崩溃率 > 0.1%
- 接口错误率 > 1%
- 严重 Bug 影响核心功能
- 用户投诉 > 5 个/天

### 回滚步骤
1. 立即停止灰度发布
2. 回滚到上一个稳定版本
3. 通知所有用户
4. 分析原因并修复
5. 重新测试后再次发布

### 回滚时间目标
- 决策时间：< 5 分钟
- 执行时间：< 30 分钟
- 总时间：< 35 分钟
