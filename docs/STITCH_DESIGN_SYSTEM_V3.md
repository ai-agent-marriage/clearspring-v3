## 📋 一、通用强制规范（所有页面必带）

### 1.1 色彩体系（不可修改）

| 色彩类型 | 色值 | 应用场景 |
|----------|------|----------|
| **主色** | `#4A5D4E`（低饱和森系墨绿） | 核心 CTA 按钮、选中态、标题强调、主图标 |
| **辅助色** | `#C9B037`（哑光金） | 里程碑标签、证书点缀、高亮提示、增值服务标注 |
| **第三色** | `#A68966`（暖棕褐） | 次要按钮、辅助描边、非核心标签 |
| **页面底色** | `#EFEEE9`（浅奶油米白） | 全页面通用背景，禁用纯白高对比底色 |
| **中性文本色** | 主文本 `#2D3748`、辅助文本 `#718096` | 标题/正文、提示文案 |
| **状态色** | 成功 `#38A169`、错误 `#E53E3E`、警告 `#ECC94B`、禁用 `#CBD5E0` | 状态标签、错误提示 |

---

### 1.2 字体规范（不可修改）

| 字体类型 | 字体家族 | 字重 | 应用场景 |
|----------|----------|------|----------|
| **标题字体** | Noto Serif（衬线字体） | 600-700 | 一级/二级标题 |
| **正文字体** | Plus Jakarta Sans（无衬线字体） | 400 | 正文、辅助文本 |

#### 小程序端字号层级
| 层级 | 字号 | 应用场景 |
|------|------|----------|
| 一级标题 | 36rpx | 页面主标题 |
| 二级标题 | 32rpx | 子模块标题 |
| 正文 | 26rpx | 表单文本、详情内容 |
| 辅助文本 | 24rpx | 提示文案、时间戳 |

#### WEB 端字号层级
| 层级 | 字号 | 应用场景 |
|------|------|----------|
| 一级标题 | 24px | 页面主标题 |
| 二级标题 | 20px | 子模块标题 |
| 正文 | 16px | 表单文本、详情内容 |
| 辅助文本 | 14px | 提示文案、备注 |

---

### 1.3 布局与组件规范（不可修改）

#### 圆角规则
- **全控件统一中等圆角 Level 2**
- 小程序端：`8rpx`
- WEB 端：`4px`
- ❌ 禁止尖锐直角
- ❌ 禁止过度大圆角

#### 间距规则
| 间距类型 | 小程序端 | WEB 端 | 应用场景 |
|----------|----------|--------|----------|
| 模块间距 | 32rpx | 16px | 卡片/模块之间 |
| 元素内边距 | 24rpx | 12px | 按钮/卡片内部 |
| 内容间距 | 16rpx | 8px | 文本/图标之间 |

#### 按钮规范
| 状态 | 样式 |
|------|------|
| **主按钮** | 主色填充 + 白色文字 |
| **次按钮** | 主色描边 + 主色文字 |
| **禁用按钮** | 灰色填充 + 浅灰文字 |
| **hover 态** | 主色加深 10% |

#### 卡片规范
- **常态**: 白色底色 + 极淡软投影（opacity 8%）
- **hover 态**: 投影加深，轻微上浮效果

#### 加载规范
- **默认**: Stitch 极简转圈加载动画
- **列表页**: 骨架屏
- **按钮加载**: 文字替换为加载动画

---

### 1.4 适配规范

#### 小程序端
- `rpx` 弹性布局
- 兼容微信全机型
- 适配全面屏底部安全区域

#### WEB 端
- 响应式布局
- 最小适配 `1366×768` 分辨率
- 核心内容区 `1200px` 居中

## 🎨 设计原则

### 1. 禅意极简
- 留白充足，无冗余装饰
- 低饱和度配色
- 水墨元素点缀（极低透明度）

### 2. 信息层级清晰
- 标题/正文/辅助文本层级分明
- 卡片布局规整
- 状态标签醒目

### 3. 合规优先
- 全程突出合规提示
- 禁止投放物种红标强警示
- 付费入口深度隐藏

### 4. 用户体验
- 操作反馈明确（Stitch 规范）
- 加载状态友好（骨架屏/转圈动画）
- 空状态引导清晰
