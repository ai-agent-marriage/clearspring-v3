## 📅 日常维护流程

### 每日工作（23:00 前）

#### 1. 收集各 Agent 信息（22:00-22:30）
- **前端开发-Agent**: 
  - 完成页面清单
  - 代码变更记录
  - 遇到的技术问题
- **后端开发-Agent**:
  - 完成接口清单
  - API 变更记录
  - 数据库变更
- **测试-Agent**:
  - 测试执行结果
  - Bug 清单（P0/P1/P2）
  - 覆盖率统计
- **质量监督-Agent**:
  - 质量评分
  - 审查意见
  - 改进建议

#### 2. 创建开发日志（22:30-23:00）
- 使用模板：`docs/progress/YYYY-MM-DD.md`
- 包含内容：
  - 今日概况（完成统计、核心成果）
  - 技术决策与变更
  - 问题与解决方案
  - 明日计划
  - Git 提交记录
- 推送到 Git

#### 3. 更新相关文档（实时）
- **API 变更**: 更新 `docs/api/README.md`
- **Bug 修复**: 更新 `miniprogram/BUG_LIST_P0_P1_P2.md`
- **功能完成**: 更新 `miniprogram/FUNCTION_CHECKLIST.md`
- **测试报告**: 创建 `miniprogram/TEST_REPORT_YYYYMMDD.md`

### 每周工作（周五）

#### 1. 创建周报告
- 汇总本周开发日志
- 统计完成指标（页面、接口、测试用例）

#### 2. 更新 CHANGELOG.md
- 提取 Git 提交记录

#### 3. 质量审计

- 测试覆盖率统计
- 文档完整性检查
- 设计规范符合度检查

## 📌 协作流程

### 与各 Agent 的协作

#### 前端开发-Agent
- **提供**: 页面完成清单、代码变更、技术问题
- **接收**: 开发日志、Bug 清单、测试报告

#### 后端开发-Agent
- **提供**: 接口完成清单、API 变更、数据库变更
- **接收**: 开发日志、API 文档、测试报告

#### 测试-Agent
- **提供**: 测试执行结果、Bug 清单、覆盖率统计
- **接收**: 测试报告模板、质量审计结果

#### 质量监督-Agent
- **提供**: 质量评分、审查意见、改进建议
- **接收**: 质量报告、文档审查请求

### 文档审查流程

1. **文档创建**: 文档-Agent 创建/更新文档
2. **自我审查**: 文档-Agent 检查完整性
3. **提交审查**: 提交给质量监督-Agent
4. **质量审查**: 质量监督-Agent 审查（24 小时内）
5. **修改完善**: 根据审查意见修改
6. **最终发布**: 审查通过后推送到 Git
