## 📝 学习笔记模板

每个学习笔记包含以下章节：

```markdown
# [项目名称] 学习笔记

## 1. 项目概览
- GitHub 地址
- Stars 数量
- 开源协议
- 核心功能

## 2. 安装配置
- 安装命令
- 配置文件
- 环境要求

## 3. 核心 API 使用
- API 列表
- 使用示例（代码）
- 参数说明

## 4. 可复用代码片段
- 核心代码
- 适配清如的修改建议

## 5. 踩坑记录
- 遇到的问题
- 解决方案

## 6. 清如项目复用建议
- 复用方式
- 修改点
- 注意事项
```
