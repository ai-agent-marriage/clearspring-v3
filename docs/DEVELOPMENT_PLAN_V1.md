## 🔧 核心模块开发（附开源代码集成）

### 🔴 模块 1：公共基础能力（必做，开源直接复用）

#### 1.1 微信授权/登录（WxJava）

**后端集成代码**:
```java
@Autowired
private WxMaService wxMaService;

public WxMaJscode2SessionResult login(String code) {
    return wxMaService.getUserService().getSessionInfo(code);
}
```

**复用价值**: 一键获取小程序用户信息，无需对接微信官方接口

---

#### 1.2 内容安全审核（微信官方 Demo）

**小程序端代码**:
```javascript
// 护生照片/文案自动审核
wx.security.imgSecCheck({
  mediaType: 1,
  image: filePath,
  success: () => {
    // 审核通过，提交数据
  },
  fail: () => {
    wx.showToast({ title: '内容违规' })
  }
})
```

**复用价值**: 直接复用官方合规审核逻辑，过审保障

---

#### 1.3 佛历/日历算法（lunar-javascript）

**小程序端代码**:
```javascript
// 直接生成佛历、宜忌、干支
import { Solar } from 'lunar-javascript'

const solar = Solar.fromDate(new Date())
const lunar = solar.getLunar()
const fo = solar.getFo()

console.log(fo.toFullString()) // 佛历日期 + 宜忌
```

**复用价值**: 完全覆盖佛历吉日模块需求，无需自己写日历算法

### 🟢 模块 2：梵音板块（音频播放开源集成）

**复用开源库**: wx-audio + wechat-audio-player

**核心功能**:
- ✅ 9 首固定音频列表、随机禅理展示
- ✅ 环形进度条、后台播放、锁屏控制
- ✅ 有效收听统计、里程碑证书触发

**核心播放代码**:
```javascript
// 小程序梵音播放页
import WxAudio from 'wx-audio'

const wxAudio = new WxAudio({
  src: 'https://xxx/梵音 1.mp3',
  loop: false,
  autoplay: true
})

// 播放完成，统计有效收听
wxAudio.onEnded(() => {
  if(播放时长 ≥ 80%){
    this.addListenCount() // 累计收听次数
  }
})
```

### 🟣 模块 5：护生订单闭环（核心盈利模块）

**复用开源**: 家政/跑腿订单全流程

**业务流程**:
```
祈福者下单 → 填写信息 → 微信支付
  ↓
机构接单 → 分配志愿者
  ↓
志愿者执行 → 上传照片/视频
  ↓
用户确认 → 生成证书 → 自动结算
  ↓
WEB 后台审核 → 合规管控
```

**订单状态流转（PRD 严格匹配）**:
```
待承接 → 待执行 → 执行中 → 待确认 → 已完成 → 已结算
```
