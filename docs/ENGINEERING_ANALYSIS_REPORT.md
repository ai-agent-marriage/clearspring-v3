## 📊 一、项目概况分析

### 1.1 项目基本信息

| 项目要素 | 详细信息 |
|----------|----------|
| **项目名称** | 清如 ClearSpring V3 |
| **项目类型** | 微信小程序 + WEB 管理后台 |
| **技术栈** | 微信原生小程序 + Java(RuoYi-Vue) + MySQL |
| **开发周期** | 4 周（2026-04-07 ~ 2026-05-04） |
| **核心目标** | 禅意静心 + 科学护生小程序 |
| **合规要求** | 弱化宗教属性，强化生态保护定位 |

---

### 1.2 产品架构分析

#### 用户端（微信小程序）
- **3 大板块**: 梵音、禅理、我的
- **3 类角色**: 祈福者（默认）、志愿者（个人践行者）、机构（合规执行机构）
- **7 个核心页面**: 首页、音频播放、禅理、物种查询、佛历吉日、护生功德林、个人中心
- **2 条业务链路**: 免费自主护生登记 + 付费委托护生服务

#### 管理端（WEB 后台）
- **5 类角色**: 超级管理员、机构管理员、内容运营、合规审核、财务专员
- **6 大模块**: 控制台、用户管理、订单管理、内容管理、财务管理、系统设置

---

### 1.3 技术架构分析

#### 前端技术栈
| 技术选型 | 具体方案 | 开源依赖 |
|----------|----------|----------|
| **小程序框架** | 微信原生小程序 | - |
| **UI 组件库** | Vant Weapp | youzan/vant-weapp |
| **音频播放** | wx.createInnerAudioContext | xingbofeng/wx-audio |
| **海报生成** | wx.createCanvasContext | jasondu/wxa-plugin-canvas |
| **佛历算法** | lunar-javascript | 6tail/lunar-javascript |
| **日历组件** | wechat-calendar | AIDeepx/wechat-calendar |

#### 后端技术栈
| 技术选型 | 具体方案 | 开源依赖 |
|----------|----------|----------|
| **后端框架** | Spring Boot + RuoYi-Vue | yangzongzhuan/RuoYi-Vue |
| **微信 SDK** | WxJava | binarywang/WxJava |
| **数据库** | MySQL 8.0+ | - |
| **云存储** | 微信云存储/火山云 | - |
| **内容安全** | 微信内容安全 API | wechat-miniprogram/security-demo |

#### 数据库设计
- **10 张核心表**: sys_role, sys_user, species, audio, zen_quote, protect_record, order_protect, certificate, org_info, system_config
- **索引优化**: openid 唯一索引、role_code 索引、order_no 主键、status 索引
- **数据初始化**: 角色数据、物种数据（50+）、音频数据（9 首）、禅理数据（300+）
