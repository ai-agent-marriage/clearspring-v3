## 技术实现要点

### 1. 数据加载流程

```javascript
async loadOrgData() {
  try {
    // 1. 显示加载状态
    wx.showLoading({ title: '加载中...' });
    
    // 2. 调用云函数
    const res = await wx.cloud.callFunction({
      name: 'org-data',
      data: { orgId, timestamp }
    });
    
    // 3. 验证响应
    if (res.result && res.result.code === 0 && res.result.data) {
      // 4. 更新数据
      this.setData({ org: res.result.data, loading: false });
      wx.hideLoading();
    } else {
      throw new Error(res.result?.msg || '数据加载失败');
    }
  } catch (error) {
    // 5. 错误处理
    wx.hideLoading();
    wx.showToast({ title: error.message, icon: 'none' });
    
    // 6. 日志上报
    wx.cloud.callFunction({
      name: 'log-error',
      data: { error: error.message, page: 'org-home', timestamp }
    });
  }
}
```

### 2. 错误处理策略

- **网络异常**：try-catch 捕获，提示用户重试
- **数据异常**：验证响应结构，抛出明确错误
- **权限异常**：云函数层面验证，返回错误码
- **超时处理**：云函数默认 3 秒超时，可配置

### 3. 加载状态管理

- 数据加载前：`wx.showLoading({ title: '加载中...' })`
- 数据加载后：`wx.hideLoading()`
- 错误发生时：`wx.hideLoading()` + `wx.showToast()`
- 刷新操作：复用加载逻辑，避免重复代码

### 4. 数据验证

