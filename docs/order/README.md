# 订单板块开发文档

## 📁 目录结构

```
pages/order/
├── create.*        # 付费委托护生下单页
├── confirm.*       # 委托订单确认&支付页
├── list.*          # 我的委托订单列表页
├── detail.*        # 委托订单详情页
└── order.*         # 订单首页（入口页）
```

## 🎯 页面功能

### 1. create - 下单页
- 合规承诺书（前置确认）
- 表单填写（日期/水域/物种/数量/增值服务/心愿）
- 实时金额计算
- 提交订单

### 2. confirm - 确认页
- 订单信息展示
- 金额明细
- 协议确认
- 支付流程

### 3. list - 列表页
- 状态 Tab 筛选（7 个状态）
- 订单卡片展示
- 动态操作按钮
- 空状态处理

### 4. detail - 详情页
- 订单进度条（5 步骤）
- 订单信息展示
- 执行材料预览
- 底部操作按钮

## 🎨 设计规范

- **主色调**: 禅意金 (#D4B87B)
- **背景色**: 宣纸底 (#EFEEE9)
- **圆角**: 中等圆角 (24rpx)
- **按钮高度**: 88rpx (最小热区)

## 📊 订单状态流转

```
已支付 → 已承接 → 已执行 → 已确认 → 已完成
                ↓
              已取消
```
