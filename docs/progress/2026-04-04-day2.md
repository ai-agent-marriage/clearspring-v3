## ⚠️ 注意事项

### 1. 插件安装
- 当前创建了简化版 painter 组件
- 生产环境建议从 GitHub 克隆完整版：
  ```bash
  git clone https://github.com/jasondu/wxa-plugin-canvas.git components/painter
  ```

### 2. 图片资源
- 物种图片使用占位符（📷 emoji）
- 实际部署需替换为真实图片资源
- 建议路径：`/assets/species/*.jpg`

### 3. 域名配置
- 海报背景图使用 picsum.photos 随机图
- 生产环境需在微信公众平台配置 downloadFile 合法域名

### 4. 权限处理
- 保存到相册需要 `scope.writePhotosAlbum` 权限
- 已实现权限检查和引导用户打开设置
