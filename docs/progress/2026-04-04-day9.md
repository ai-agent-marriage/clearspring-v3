## 🔧 技术要点

### 1. Canvas 2D 适配
```javascript
const dpr = wx.getSystemInfoSync().pixelRatio
canvas.width = res[0].width * dpr
canvas.height = res[0].height * dpr
```

### 2. 图表生命周期管理
```javascript
onReady() {
  this.initCharts()
}

onUnload() {
  if (this.data.chart) {
    this.data.chart.dispose()
  }
}
```

### 3. 实时数据刷新
```javascript
startAutoRefresh() {
  this.refreshTimer = setInterval(() => {
    this.refreshData()
  }, 30000)
}
```
