## 🎯 synthesizeWatermark 功能详情

### 核心功能

✅ **视频水印后端合成**（GPS + 时间 + 任务 ID）

### 主要特性

1. ✅ **GPS 坐标格式化**
   - 支持经纬度
   - 格式：`39.9042°N 116.4074°E`
   - 精度：6 位小数

2. ✅ **时间格式化**
   - 支持时间戳转换
   - 格式：`2026/04/05 20:22:00`
   - 时区：Asia/Shanghai

3. ✅ **任务 ID 显示**
   - 唯一标识
   - 便于追溯

4. ✅ **水印配置**
   - 字体大小：24px
   - 字体颜色：白色
   - 描边颜色：黑色
   - 位置：左下角
   - 透明度：80%

5. ✅ **审计日志**
   - 记录所有水印操作
   - 便于问题追溯

### 输入参数

```javascript
{
  fileID: "cloud://xxx/video.mp4",  // 云文件 ID
  watermarkData: {
    gps: "39.9042°N 116.4074°E",     // GPS 坐标
    timestamp: 1712318400000,        // 时间戳
    taskId: "TASK_20260405_001"      // 任务 ID
  }
}
```

### 输出结果

```javascript
{
  success: true,
  message: "水印合成成功",
  data: {
    fileID: "cloud://xxx/video_watermarked.mp4",
    watermarkText: "任务 ID: TASK_20260405_001 | 时间：2026/04/05 20:22:00 | 位置：39.9042°N 116.4074°E",
    duration: 15.5,
    size: 1024000
  }
}
```

### 技术实现

**注意**: 由于云函数环境限制，实际视频处理需要：

1. **方案 A**: 使用云托管（推荐）
   - 部署 ffmpeg
   - 完整视频处理能力
   - 无执行时间限制

2. **方案 B**: 使用云服务商 API
   - 火山云视频处理
   - 腾讯云 MPS
   - 阿里云 MPS

3. **方案 C**: 前端预览 + 后端合成
   - 前端 Canvas 预览水印效果
   - 后端调用专业视频处理服务
