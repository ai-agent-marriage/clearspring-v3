## 示例：用户登录用例

### 用例基本信息

| 字段 | 内容 |
|------|------|
| 用例 ID | TC001 |
| 用例名称 | 用户打开小程序并授权登录 |
| 优先级 | P0 |
| 测试类型 | 功能测试 |

### 前置条件

1. 小程序可正常访问
2. 测试账号已注册
3. 网络连接正常

### 测试数据

- 测试账号：test_user
- 测试密码：test123

### 操作步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 打开小程序 | 小程序首页加载成功 |
| 2 | 点击登录按钮 | 弹出授权对话框 |
| 3 | 点击授权按钮 | 授权成功，获取用户信息 |
| 4 | 验证用户信息显示 | 页面显示用户昵称和头像 |
| 5 | 验证进入首页 | 首页服务列表可见 |

### 断言点

1. 登录按钮可见
2. 授权对话框弹出
3. 用户信息区域可见
4. 首页服务列表可见

### 证据采集点

- 步骤 2：登录按钮截图
- 步骤 4：用户信息截图
- 失败时：自动截图 + 视频
