《科学护生合规承诺书》

为维护生态平衡，本人在此郑重承诺：

1. 严格遵守国家相关法律法规，不投放任何外来入侵物种（如巴西龟、鳄龟、福寿螺等）。

2. 仅在政府允许的指定水域进行自主护生活动。

3. 关注物种健康状况，确保投放过程符合动物福利要求。

4. 护生现场保持环境整洁，不遗留任何塑料包装或废弃物。

5. 坚持科学精神，以保护当地生态多样性为首要原则。
