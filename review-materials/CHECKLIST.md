## 🚀 提交流程

### 1. 登录微信公众平台
```
https://mp.weixin.qq.com
```

### 2. 进入版本管理
```
左侧菜单 → 管理 → 版本管理
```

### 3. 提交审核
```
点击"开发版" → "提交审核"
```

### 4. 填写信息
- [ ] 上传功能截图（按顺序）
- [ ] 确认隐私政策和服务协议
- [ ] 填写测试账号信息
- [ ] 填写审核备注（使用上方模板）

### 5. 确认提交
- [ ] 检查所有信息
- [ ] 点击提交

## ⏱️ 审核时间线

| 阶段 | 时间 | 说明 |
|------|------|------|
| 提交审核 | Day 0 | 完成所有材料准备并提交 |
| 审核中 | Day 1-3 | 等待微信审核，通常 1-3 个工作日 |
| 审核通过 | Day 3-4 | 收到通过通知，可发布上线 |
| 审核驳回 | Day 1-3 | 根据驳回原因修改后重新提交 |

## 🔔 审核状态跟踪

### 查看审核进度
```
微信公众平台 → 管理 → 版本管理 → 审核中
```

### 接收审核通知
- 审核结果会通过"微信团队"服务通知发送
- 绑定管理员微信会收到推送消息

### 审核驳回处理
1. 查看驳回原因（微信服务通知或后台）
2. 根据原因修改小程序或补充材料
3. 重新提交审核
4. 常见驳回原因见 review-materials/README.md
