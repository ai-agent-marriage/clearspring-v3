## 📖 使用说明文档

### 小程序简介

**清如 ClearSpring** 是一款提供佛教放生服务预订的微信小程序，帮助用户预约专业执行者进行如法放生活动，同时提供佛教文化学习、功德林等功能。

### 核心功能

1. **放生服务预订**
   - 浏览可预订的放生服务
   - 选择服务类型、时间、地点
   - 提交订单并等待执行者接单
   - 查看服务执行情况和证据

2. **执行者资质展示**
   - 展示经过审核的执行者信息
   - 执行者资质认证流程
   - 执行者服务评价体系

3. **佛教文化学习**
   - 放生仪轨教学
   - 正念冥想练习
   - 佛教百科知识查询

4. **功德林系统**
   - 记录用户放生功德
   - 功德树成长体系
   - 功德排行榜

### 用户使用流程

```
1. 用户打开小程序 → 微信授权登录
2. 浏览服务列表 → 选择服务类型
3. 填写服务信息 → 提交订单
4. 等待执行者接单 → 执行者完成服务
5. 查看服务证据 → 确认完成并评价
```

### 步骤 1：登录微信公众平台

1. 访问 https://mp.weixin.qq.com
2. 使用管理员微信扫码登录

1. 左侧菜单 → 管理 → 版本管理
2. 确认当前有"开发版"小程序

### 步骤 3：提交审核

1. 点击"开发版"右侧的"提交审核"按钮
2. 填写审核信息：

**功能页面截图**
- 上传前面准备的所有功能截图
- 按页面逻辑顺序排列
- 确保截图清晰、完整

**隐私协议**
- 确认已包含隐私政策页面
- 确认已包含用户协议页面

**测试账号**
- 如需要登录，填写测试账号信息
- 如使用微信授权登录，填写"使用微信授权登录，无需账号密码"

**备注信息**
```

用户可浏览并预订放生服务，执行者接单后完成服务并上传证据。
小程序包含以下主要功能：
1. 放生服务预订系统
2. 执行者资质认证与展示
```

## ⚠️ 常见审核驳回原因及应对

### 1. 功能与类目不符

**原因**：小程序实际功能与选择的类目不一致

**应对**：
- 确保选择正确的类目（建议：工具 - 效率 / 生活 - 生活服务）
- 如涉宗教内容，可能需要特殊资质

### 2. 隐私政策不规范

**原因**：隐私政策未说明信息收集使用规则

**应对**：
- 确保隐私政策包含信息收集、使用、保护说明
- 明确说明各权限的使用目的
- 提供用户权利说明和联系方式

### 3. 功能无法体验

**原因**：审核人员无法正常使用核心功能

**应对**：
- 确保测试账号可用
- 确保所有功能流程可正常走通
- 在备注中详细说明使用流程

### 4. 涉及敏感内容

**原因**：涉及宗教、迷信等敏感内容

**应对**：
- 强调佛教正信文化，避免迷信内容
- 说明不涉及宗教募捐、化缘
- 强调科学放生、生态保护理念
