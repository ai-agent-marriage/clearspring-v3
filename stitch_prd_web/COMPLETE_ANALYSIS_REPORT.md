## 💡 技术建议

### 小程序端
1. **使用微信原生开发**（非 uni-app）
   - 更好的性能
   - 更完善的云开发支持
   - 符合现有架构

2. **组件化策略**
   - 提取通用组件：Header、Card、Button、Form
   - 业务组件：OrderCard、Certificate、EvidenceUploader
   - 工具函数：日期格式化、数据脱敏

3. **状态管理**
   - 使用全局 App Data
   - 复杂状态考虑使用轻量级状态管理

### Web 端
1. **技术选型建议**
   - 前端框架：Vue 3 + Vite（符合团队技术栈）
   - UI 组件库：Element Plus / Ant Design Vue
   - 图表库：ECharts（已有集成经验）

2. **架构设计**
   - 前后端分离
   - RESTful API / GraphQL
   - JWT 认证

3. **响应式支持**
   - 桌面端优先
   - 适配平板（1024px+）
   - 移动端可选（H5 已有）
