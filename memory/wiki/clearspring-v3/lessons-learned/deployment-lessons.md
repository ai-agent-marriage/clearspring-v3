## ✅ 成功经验

### 1. SSH 密钥轮换

**机制**: 90 天周期，自动轮换脚本

**配置**:
```bash
# SSH 密钥轮换脚本
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa
```

---

### 2. 临时密钥文件

**机制**: GitHub Actions 使用临时文件，部署后立即清理

**配置**:
```yaml
- name: Cleanup SSH key
  run: rm -f ~/.ssh/id_rsa
```

---

### 3. 自动回滚机制

**机制**: 部署失败自动回滚到上一版本

**配置**:
```yaml
- name: Rollback on failure
  run: pm2 revert
```
