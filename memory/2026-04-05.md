## 📈 部署流程（最终版）

```yaml
name: Simple Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Deploy to Volcano
        uses: appleboy/ssh-action@master
        with:
          host: ${{ secrets.VOLCANO_HOST }}
          username: ${{ secrets.VOLCANO_USER }}
          key: ${{ secrets.VOLCANO_SSH_KEY }}
          script: |
            cd /root/clearspring-v3
            git pull origin main
            npm install
            pm2 restart clearspring-api
```
